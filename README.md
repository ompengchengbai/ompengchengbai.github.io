# Pengcheng Bai academic homepage

A minimal static academic homepage. No build system is required.

## Publish with GitHub Pages

1. Create a repository named `YOUR_GITHUB_USERNAME.github.io`.
2. Upload `index.html`, `styles.css`, and `profile.jpg` to the repository root.
3. Open `https://YOUR_GITHUB_USERNAME.github.io`.

The SSRN and coauthor homepage links are already embedded in `index.html`.
